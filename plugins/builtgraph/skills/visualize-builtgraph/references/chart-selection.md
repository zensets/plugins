# Chart selection

- Project pipeline by stage or time: stacked bars or timeline.
- Opportunity comparison across several metrics: aligned dot plot or scorecard table.
- Owner-to-firm relationship history: filtered bipartite network plus ranked edge table.
- Geographic concentration: map only when coordinates or verified geographies exist; otherwise use ranked bars.
- Market composition: bars; avoid pie charts when categories are numerous.
- Award or participation trend: line chart with coverage changes annotated.

Always include a source/as-of note and a row-level export or provenance table.
