# Query Builtgraph

Read [references/live-mcp-playbook.md](references/live-mcp-playbook.md). Use the current MCP
descriptions as the authoritative contract for available research actions.

## Workflow

1. Define the subject, decision, geography, time window, relevant role, and as-of date from the
   request. Ask only for missing context that would materially change the research.
2. Choose the smallest task-oriented path supported by Builtgraph. Resolve ambiguous subjects
   before comparing them, and preserve returned record identifiers.
3. Gather the core evidence, then follow only those relationships or adjacent facts likely to change
   the answer. Avoid broad exploratory walks that add volume without relevance.
4. Check whether identity, scope, freshness, or incomplete evidence could change a negative or
   comparative conclusion.
5. Lead with the decision-relevant answer. Show a short prioritized set of findings, the evidence
   supporting them, scope/as-of date, material uncertainty, and the most valuable next step. Offer
   deeper supporting detail only when it would help the user act or verify the conclusion.

Use only the capabilities and fields exposed by the current MCP. If part of the request is not
supported, say so narrowly and distinguish any external enrichment from Builtgraph evidence.
