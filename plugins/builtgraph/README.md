# Builtgraph Plugin

Builtgraph packages nine AEC research and business-development skills with the hosted Builtgraph MCP server at `https://builtgraph.com/mcp`.

## Workflows

- Company ICP and target sectors
- Potential opportunity discovery
- Competitor research
- RFP go/no-go assessment
- Client research
- Emerging developer discovery
- Evidence-backed querying
- Opportunity scoring
- Relationship and pipeline visualization

The plugin currently uses model-readable structured results, Markdown tables, and exportable artifacts. Native MCP Apps components are not included in this release.
